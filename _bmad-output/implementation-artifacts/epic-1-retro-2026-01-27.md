## ⚠️ Challenges & Lessons Learned
1.  **Dependency Documentation Mismatch:** The `piper-tts` integration initially failed because we used an outdated API (`synthesize_stream_raw`).
    *   **Lesson:** Always verify the installed library version and inspect its attributes/methods (`dir()`) if documentation is ambiguous or outdated.
2.  **Initialization Gaps:** The application failed to capture input because `input_handler.start()` was missing in `main.py`.
    *   **Lesson:** Explicit lifecycle management (start/stop) is good, but we must ensure we actually call the start methods in the composition root (`main.py`).
3.  **Strict Typing Overhead:** Getting to zero type errors required significant effort (fixing `Any`, Protocol definitions, mocking).
    *   **Lesson:** It is worth it. It caught potential bugs and makes refactoring for Epic 2 safer.
