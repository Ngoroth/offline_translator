  <name>Create StartupVerifier class in core/startup.py</name>
  <files>src/app/core/startup.py</files>
  <action>
Create a new file `src/app/core/startup.py` with a `StartupVerifier` class that:

1. Takes `AppSettings` in constructor
2. Has `verify_all() -> bool` method that runs checks and exits on failure
3. Has `verify_models() -> bool` method that:
   - Checks STT model exists (only if path looks like local file - see config.py:134-137 for pattern)
   - Checks LLM model exists
   - Checks TTS model exists
   - Checks speaker_a_voice exists (if configured)
   - Checks speaker_b_voice exists (if configured)
   - On failure: prints "ERROR: Missing model files:" followed by paths, then "Run: uv run python scripts/download_models.py", sets exit_code=1, returns False
4. Has `verify_audio_devices() -> bool` method that:
   - Uses `get_default_input_device()` and `get_default_output_device()` from devices.py
   - On failure: prints "ERROR: No audio devices available", then "Available devices:" with formatted list showing index, name, and (input/output) type, sets exit_code=2, returns False
5. Uses `sys.exit()` with the exit_code when verification fails

**Important constraints (from user decisions):**
- Plain text output only (no colors, no JSON, no rich formatting)
- Console output only (no log files)
- Exit code 1 for missing models, 2 for missing audio
- Run models check first (faster), then audio check

**Pattern to follow from RESEARCH.md:**
```python
import sys
from pathlib import Path
from app.core.audio.devices import list_audio_devices, get_default_input_device, get_default_output_device

class StartupVerifier:
    def __init__(self, settings):
        self.settings = settings
        self.exit_code = 0

    def verify_all(self) -> bool:
        if not self.verify_models():
            sys.exit(self.exit_code)
        if not self.verify_audio_devices():
            sys.exit(self.exit_code)
        return True
    # ... rest of implementation
```
