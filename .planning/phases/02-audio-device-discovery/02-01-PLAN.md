<task type="auto">
  <name>Task 1: Create audio device discovery module</name>
  <files>src/app/core/audio/devices.py</files>
  <action>
Create a new module `src/app/core/audio/devices.py` with the following functions:

1. `AudioDevice` dataclass with fields: `index: int`, `name: str`, `is_input: bool`, `is_output: bool`, `is_default: bool`, `sample_rate: int | None`

2. `list_audio_devices() -> list[AudioDevice]`: Query all audio devices using `sounddevice.query_devices()`. Parse results into AudioDevice objects. Mark default input/output devices based on `sounddevice.default.device`.

3. `get_default_input_device() -> AudioDevice | None`: Find and return the default input device. Return None if no input device available.

4. `get_default_output_device() -> AudioDevice | None`: Find and return the default output device. Return None if no output device available.

5. `resolve_device(device_name: str | int | None, is_input: bool) -> int | str | None`:
   - If `None`, return default device index for the direction
   - If `int`, return as-is (already an index)
   - If `str`:
     - Try to match device name exactly (case-insensitive)
     - If not found, return the string as-is (for ALSA device names like "plughw:1,0")
     - Log a warning if device name not found in enumeration

Platform considerations:
- On Linux/ALSA, device strings like "plughw:1,0" should be passed through unchanged for arecord
- On Windows/macOS, device names should be resolved to indices for sounddevice

Use loguru for logging. Add type hints to all functions.
  </action>
  <verify>uv run basedpyright src/app/core/audio/devices.py</verify>
  <done>Module imports successfully, all functions have type hints, basedpyright reports 0 errors</done>
</task>
